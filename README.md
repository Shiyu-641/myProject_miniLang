## 1. 项目目标
实现一个基于python的迷你语言解释器  
第一代实现内容：支持加减乘除运算，括号

## 2. MiniLang 是什么
1+1=2 17*3=51 (1+3)/2=2  
用户程序输入表达式，解释器解释并计算表达式的结果

## 4. 语法
### 4.1词法规则
- 数字0～9识别为NUMBER  
（连续数字组成一个NUMBER）  
- +-*/()识别为OPERATOR "+" "-" "*" "/" "(" ")"  
空格跳过  
- 运算符优先级 () > * = / > + = - 同级别的运算符表达式先读取的运算符优先级高于后读取的
（同级别运算符从左向右结合，因此先读取的运算符成为后读取运算符的左侧子树）
### 4.2语法规则
- EXPRESSION从左往右读，  
NUMBER(3) PLUS NUMBER(2)  
- 读数字直到碰到第一个运算符，第一段连续数字组成第一个NUMBER，继续读取下一个数字，直到碰到下一个运算符或结束命令，第二段连续数字组成第二个NUMBER，以此类推。NUMBER只能作为叶节点，OPERATOR作为根节点，第一个数字作为第一个运算符的左子树，第二个数字作为右子树，  
- 变成多项式的时候，遇到第一个运算符后继续读取，直到遇到下一个运算符，在第一个运算符的基础上，如果下一个遇到的运算符是  
  - 高优先级的运算符，往下构建，将新运算符作为第一个运算符的右子树（叶节点），将其左边的数作为新运算符的左节点，  
  - 遇到低优先级的，将其右边的数作为当前运算符的右子树，并将当前已经构建好的表达式作为新运算符的左子树，右子树依据上述规则继续执行，直到遇到结束符  
- 例：  
（（2+3）-4）+1*2
```
    +
  -   *
 + 4 1 2
2 3

 +
2 *
 3 4
 
  +
 * 5
2 3

   +
  - 5
 + 4
2 3
```
- 当Parser从左往右读到(，开始解析一个新的EXPRESSION，按照正常运算规则构建AST，直到遇到对应的)，括号内部构建完成以后，将之前构建好的子树作为一个整体返回给外层 Expression，并作为外层运算符的一个操作数继续参与 AST 构建。
```
    -
  *   5
2   +
   3 4
```

## 5. AST
AST节点：NUMBER OPERATOR  
NUMBER：数字value  
运算符节点：+-*/  
左右子树是最小单位是NUMBER或完整表达式  
括号不出现在AST中 

## 6. Interpreter
NUMBER 返回 value
+ 计算 left + right
- 计算 left - right
* 计算 left * right
/ 计算 left / right  
在下面的是含低优先级运算符的表达式，先计算子树，再使用子树的计算结果计算父节点  

## 7. Error handling
错误情况：  
当连续读取多个NUMBER，且中间没有运算符  
连续读取多个基本运算符号（+-*/）  
左右括号不配对（左右括号数不相等）  
(左边是数字  
)右边是数字  
 ()内部表达式不满足上述表达式要求或为空  
 发现错误报错，停止解析
